# CS50x — My Computer Science Journey

I'm currently learning computer science through **CS50x** from Harvard.

This repository contains my notes, projects, and progress as I work through the course.

## Week 0 — Scratch

Week 0 gave me my first deeper look into **how computers actually work**, rather than only how to write code.

### What I Learned

#### How Computers Work

I learned the basic idea of how computers process information and how they can represent different kinds of data using bits.

A computer ultimately works with **binary — 0s and 1s** — and uses these basic states to represent and process information.

#### Machine Language

I learned about **machine language**, the low-level instructions that computers can directly understand.

It was interesting to see how programming languages were developed to make it easier for humans to give instructions to computers instead of writing everything directly in machine code.

This introduced me to the idea of **abstraction** — building higher-level tools on top of lower-level systems.

#### Programming Languages

I learned why programming languages exist and how they allow humans to write instructions in a much more understandable way.

Instead of thinking only in terms of machine instructions, programmers can use languages that provide higher-level concepts such as:

* Variables
* Functions
* Conditions
* Loops
* Events
* Data structures

#### Artificial Intelligence

I also got an introduction to **Artificial Intelligence** and what it means for machines to perform tasks that we normally associate with human intelligence.

I learned that AI is not simply "magic" or a computer thinking exactly like a human. It involves algorithms, data, computation, and different techniques for getting computers to solve problems or make predictions.

#### Algorithms

I learned that an **algorithm** is essentially a step-by-step procedure for solving a problem.

This is one of the ideas I found most important because programming isn't just about writing code. It's about figuring out **how to solve a problem** and then expressing that solution in a form a computer can execute.

#### Scratch

Finally, I learned how these programming concepts can be implemented using **Scratch**, a visual programming language.

Even though Scratch uses blocks instead of traditional code, I was still able to work with fundamental programming concepts such as:

* Variables
* Conditions
* Loops
* Functions
* Events
* Input and output
* Algorithms

This helped me understand that programming is fundamentally about **logic and problem solving**, not just syntax.

## What I Took Away

The biggest thing I learned from Week 0 is that computer science is much bigger than simply writing code.

It starts with understanding how computers work, how information is represented, how humans communicate instructions to machines, and how algorithms can be used to solve problems.

I'm looking forward to continuing with the rest of CS50x and learning how these ideas translate into real programming languages and larger systems.
